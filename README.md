# CS2OpenDev SchemaTracker — latest artifacts channel

Machine-maintained branch holding ONLY the newest committed build's artifact
set (`artifacts/<build_id>/`), the cumulative schema-evolution data
(`artifacts/schema_evolution/<platform>.json`), the artifact schemas
(`schemas/`), and the assets inventory. Read `LATEST.json` for the current
build id and platforms. Updated by the publish-latest workflow on every
artifact push to main; history is append-only so submodule pins stay
resolvable. Full history, docs, and the extraction tool live on
[main](../../tree/main).
